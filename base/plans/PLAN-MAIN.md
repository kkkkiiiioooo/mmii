# PLAN-MAIN — Plano principal do agente

agentes/SEU_NOME_DE_AGENTE/plans/PLAN-MAIN.md ao comecar o trabalho.

Regras de planos:
- O plano principal vive em PLAN-MAIN.md e e EDITADO continuamente (nao crie PLAN-002, PLAN-003... para a mesma linha de trabalho).
- Planos auxiliares receem NOME por assunto, ex.: PLAN-TESTES.md, PLAN-EXECUCAO.md, PLAN-AMBIENTE.md.
- Marque neste plano o status de cada fase e aponte para os planos auxiliares quando existirem.
