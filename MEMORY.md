# MEMORY

## Objetivo
Registrar descobertas reutilizaveis para compartilhamento entre agentes.

## Regras
- Antes de agir, reescreva a solicitacao do usuario de forma clara, curta e fiel a intencao original.
- Registre apenas memorias uteis, verificaveis e reutilizaveis.
- Cada memoria deve ter no maximo 500 caracteres.
- Nao duplique memorias. Se ja existir uma semelhante, atualize a entrada existente.
- Priorize fatos, decisoes, padroes, restricoes e achados tecnicos.
- Evite ruido, opinioes e historico irrelevante.

## Formato
- [TITULO CURTO] descricao objetiva da descoberta, contexto minimo e impacto pratico.
