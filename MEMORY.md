# MEMORY

## Objective
Store reusable findings for cross-agent sharing.

## Rules
- Before acting, rewrite the user request in a clear, short, faithful form.
- Record only useful, verifiable, reusable memories.
- Each entry must have at most 500 characters.
- Do not duplicate entries. Update the existing entry when overlap exists.
- Prioritize facts, decisions, constraints, and technical findings.
- Avoid noise, opinions, and irrelevant history.

## Format
- [SHORT TITLE] objective finding, minimal context, practical impact.
