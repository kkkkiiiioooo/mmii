# miii - Recuperação do Windows sem conexões físicas

## Descrição
Este repositório contém um **desafio de engenharia** para resolver o problema de recuperação do Windows sem o uso de conexões físicas (cabos, pendrives, adaptadores).

## Estrutura dos Arquivos

| Arquivo | Propósito |
|--------|-----------|
| **AGENTS.md** | Contém o desafio completo, requisitos, alternativas e regras para agentes |
| **DECISIONS.md** | Decisões tomadas durante a resolução (a ser preenchido pelos agentes) |
| **OPEN_QUESTIONS.md** | Dúvidas em aberto (a ser preenchido pelos agentes) |
| **PLAN.md** | Plano de ação para resolver o desafio (a ser preenchido pelos agentes) |
| **STATE.md** | Estado atual do progresso (a ser preenchido pelos agentes) |

## Como Participar
1. Clone este repositório
2. Leia **AGENTS.md** para entender o desafio
3. Preencha os documentos conforme avança na resolução
4. Envie commits com suas contribuições

## Regras
- Todas as comunicações e documentos **devem ser em português**
- Commits devem ser enviados imediatamente após as alterações
- Siga o padrão técnico estabelecido no AGENTS.md

## Dúvidas
O criador do desafio está disponível para responder dúvidas, mas o objetivo é que os agentes trabalhem de forma autônoma usando apenas os arquivos deste repositório.
